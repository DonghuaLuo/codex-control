# Changelog

All notable changes to this project will be documented in this file.

## v0.1.1 - 2026-04-06

Collaboration and repository hygiene update.

### Added

- GitHub issue forms for bugs, feature requests, and usage questions
- Pull request template and CODEOWNERS
- `SECURITY.md` and `CODE_OF_CONDUCT.md`
- Documentation links for collaboration and security policies

## v0.1.0 - 2026-04-06

Initial public release.

### Added

- Windows PowerShell entrypoints for running gated Codex workflows
- Persistent run state, task history, assignment records, failure records, and agent outputs
- Automatic planning flow with fallback task generation
- Finish-gate enforcement with verify, fix, and reverify loops
- External blocker tracking and unblock flow
- Self-tests for planner, wrapper, orchestration, and gate behavior
- Starter verification profiles and example templates
- English and Chinese project documentation
