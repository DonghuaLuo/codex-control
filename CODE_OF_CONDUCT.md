# Code of Conduct

## Our Standard

This project exists to help people build real automation workflows. Keep discussions respectful, direct, and useful.

Examples of behavior that help:

- being specific
- sharing repro steps
- disagreeing on the mechanism, not attacking the person
- improving docs when something is confusing

Examples of unacceptable behavior:

- harassment or personal attacks
- doxxing
- spam
- bad-faith issue flooding
- hostile or discriminatory language

## Enforcement

Project maintainers may remove comments, close threads, or block participation when behavior is clearly harmful to the project or its contributors.

## Reporting

If you hit a conduct problem, open a private channel through GitHub or contact the maintainer directly through repository contact options.
